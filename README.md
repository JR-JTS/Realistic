# 🛸 Drone Shadow Remover & Color Restorer

드론 항공사진의 그림자를 자동 탐지하고, 그림자 영역의 **색상을 복원**하는 Desktop 전용 툴입니다.  
AI (CNN) + 전통 CV 방법을 혼합하여 빠르고 정확하게 처리합니다.

---

## 🖥️ 실행 방법

### Windows
```
run.bat  더블클릭  (또는 명령 프롬프트에서 실행)
```

### macOS / Linux
```bash
chmod +x run.sh
./run.sh
```

### 직접 실행
```bash
# 1. 패키지 설치 (최초 1회)
python install.py

# 2. 앱 실행
python main.py
```

---

## 📋 사용법

1. **입력 폴더 선택** — 드론 사진이 들어있는 폴더를 선택합니다
2. **출력 폴더 선택** — 결과를 저장할 폴더를 선택합니다 (자동 생성)
3. **[📂 파일 스캔]** 버튼 클릭 — 폴더 내 이미지 파일 목록을 불러옵니다
4. **파라미터 조정** — 필요에 따라 슬라이더 조정
5. **[▶ 처리 시작]** 버튼 클릭 — 배치 처리 시작
6. 결과는 출력 폴더에 `파일명_restored.jpg/png` 로 저장됩니다

## 🔬 처리 파이프라인

```
드론 사진
    │
    ▼
[1] 그림자 탐지
    ├── HSV 명도(V) 낮은 영역
    ├── Lab L채널 낮은 영역
    ├── YCrCb (Y 낮음 + Cb 높음 = 푸른 그림자)
    └── 채도/명도 비율  →  4개 투표, 3/4 이상이면 그림자
        + 형태학 정제 (close/open)
        + Soft mask (가우시안 페더링)
    │
    ▼
[2] 색상 복원  (핵심)
    ├── 라디오메트릭 보정: 채널별 gain + offset 추정
    │     그림자/비그림자 통계 비교 → 원래 색상 역추정
    ├── Lab 색 전달 (Reinhard): 비그림자 색상 통계를 그림자에 전달
    │     → 파란 색조 제거 + 원래 색온도 복원
    ├── Multi-Scale Retinex: 조명 성분 제거 → 반사율(원래 색) 강조
    └── AI (ColorRestorationNet): 잔차 학습으로 미세 색상 보정
    │
    ▼
[3] 선명화
    ├── NL-Means 노이즈 제거
    ├── CLAHE (적응형 히스토그램) — 내부 디테일 복원
    └── Unsharp Masking — 고주파 선명도 향상
    │
    ▼
결과 저장
    ├── {name}_restored.png   처리된 이미지
    └── {name}_compare.jpg    4분할 비교 (원본|마스크|복원|diff)
```

## ⚙️ 파라미터 설명

| 파라미터 | 범위 | 권장 | 설명 |
|----------|------|------|------|
| 탐지 민감도 | 0.1 ~ 1.0 | **0.45 ~ 0.55** | 높을수록 더 많이 탐지 (오탐 주의) |
| 마스크 페더링 | 5 ~ 60 | **20 ~ 30** | 경계 부드럽게 (값 크면 자연스러운 블렌딩) |
| 조명 보정 강도 | 0 ~ 1.0 | **0.75 ~ 0.85** | 밝기+색상 게인 보정 강도 |
| 색 전달 강도 | 0 ~ 1.0 | **0.55 ~ 0.70** | Lab 색상 통계 전달 강도 |
| Retinex 강도 | 0 ~ 0.6 | **0.25 ~ 0.35** | 반사율 강조 강도 (과하면 부자연) |
| 노이즈 제거 | 1 ~ 15 | **5 ~ 8** | 그림자 영역 노이즈 제거 |
| 선명도 | 0.5 ~ 3.0 | **1.3 ~ 1.6** | Unsharp Mask 강도 |
| CLAHE | 1.0 ~ 5.0 | **1.8 ~ 2.5** | 그림자 내부 대비 향상 |

## 📁 프로젝트 구조

```
webapp/
├── main.py                  ← Desktop 앱 (Tkinter GUI) 실행 진입점
├── run.bat                  ← Windows 실행 스크립트
├── run.sh                   ← Linux/macOS 실행 스크립트
├── install.py               ← 패키지 설치 스크립트
├── requirements.txt
├── src/
│   ├── shadow_detection.py  ← 그림자 탐지 (CV + UNet CNN)
│   ├── color_restoration.py ← 색상 복원 (핵심 알고리즘)
│   └── pipeline.py          ← 처리 파이프라인 + 배치 유틸
└── models/                  ← AI 모델 (.pth) 저장 위치
    ├── shadow_detector.pth  (선택)
    └── color_restore.pth    (선택)
```

> 💡 `models/` 폴더에 사전학습 모델(.pth)이 없어도 CV 방법으로 완전히 동작합니다.

## 🖥️ GUI 기능

- **폴더 선택** — 입력/출력 폴더를 드래그&드롭 또는 다이얼로그로 선택
- **파일 스캔** — JPG/PNG/TIFF/BMP/WEBP 자동 스캔 (하위폴더 재귀 옵션)
- **미리보기** — 원본 / 복원 / 비교 탭 전환 가능
- **진행바** — 전체 처리 진행률 실시간 표시
- **처리 통계** — 평균 그림자 비율, 처리 속도, 경과 시간
- **처리 로그** — 파일별 처리 결과 실시간 로그
- **동시 처리** — 1/2/4 스레드 선택으로 멀티코어 활용
- **중단 기능** — 언제든지 처리 중단 가능
